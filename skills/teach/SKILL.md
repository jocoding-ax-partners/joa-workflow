# joa:teach

워크플로 6단계(사용자 이해)를 담당한다. 이 스킬 자체는 순서만 서술하고, 통과 판정은 전부
`${CLAUDE_PLUGIN_ROOT}/bin/joa.mjs` 가 한다.

## 1. 진입 가드

가장 먼저 실행한다:

```bash
node ${CLAUDE_PLUGIN_ROOT}/bin/joa.mjs require teach
```

exit 1 이면 **즉시 멈추고** 스크립트가 출력한 문장을 그대로 사용자에게 전달한다.

## 2. 왜 이 단계가 있는가

앞 단계(`joa:plan`)에서 기획을 사실상 AI 가 다 짰다. 사용자가 이해 없이 그대로 루프
구현으로 들어가면, 나중에 결과가 계획과 맞는지 **판정할 수 있는 사람이 아무도 없다.** 이
단계는 그 판정 능력을 사용자에게 되돌려주는 관문이다.

## 3. 설명 방식

계획 문서를 **페이지 단위로 나눠** 설명한다. 한 번에 전부 던지지 않는다.

**교과서처럼 점진 딥다이브** — 쉬운 것부터 시작해서 페이지마다 깊이를 더한다. 처음부터
세부 구현까지 한 번에 쏟아내지 않는다. 나뉜 페이지를 순서대로 진행하고, 각 페이지에서
사용자가 질문하면 다음 페이지로 넘어가기 전에 답한다.

## 4. 종료 게이트

이 게이트는 **기계로 잴 수 없다** — 이해했는지는 사용자 본인만 안다. 사용자가 이해 완료를
직접 선언해야 통과다. 스스로 "충분히 설명했다"고 판단해 넘어가지 않는다.

설명한 페이지 목록을 증거에 남긴다. 빠뜨린 페이지가 있었는지 나중에라도 확인할 수 있어야
한다:

```bash
node ${CLAUDE_PLUGIN_ROOT}/bin/joa.mjs pass teach "설명한 페이지: <목록>. 사용자 이해 완료 선언 <날짜>"
```
